# Лабораторная работа 3, часть 1 — ООП: операции над матрицами 7×7

Консольное приложение на Java с интерактивным меню и хранением результатов в PostgreSQL.

## Пункты меню

1. Вывести все таблицы из базы данных PostgreSQL
2. Создать таблицу в базе данных PostgreSQL
3. Ввести две матрицы с клавиатуры, сохранить каждую в PostgreSQL с форматированным выводом
4. Перемножить, сложить, вычесть, возвести в степень матрицы, сохранить результаты в PostgreSQL и вывести
5. Сохранить результаты из PostgreSQL в Excel и вывести их в консоль

- `ArrayPI` (public) — две матрицы 7×7, ввод с клавиатуры.
- Каждая операция — отдельный наследник `ArrayPI` с модификатором `public final`: `Umnozhenie`, `Slozhenie`, `Vychitanie`, `Stepen` (матричная степень A^n и B^n, 0 ≤ n ≤ 20).
- Вычисления в `BigInteger`, в таблице — `NUMERIC`, поэтому переполнения нет.

Каждый пункт меню — отдельный класс-наследник абстрактного класса `PunktMenu` (`VyvodTablic`, `SozdanieTablicy`, …). Работа с БД и общие методы ввода — в классе `Baza`.

## Что нужно для запуска

- JDK 17 или новее (проект настроен на JDK 25).
- PostgreSQL на `localhost:5432`, база `postgres`, пользователь `postgres`, пароль `postgres`.
  Если у вас другие данные, поменяйте константы `URL`, `USER`, `PASSWORD` в `src/Baza.java`.
- Драйвер PostgreSQL JDBC уже лежит в папке `lib/` и подключён к проекту.

## Запуск

**IntelliJ IDEA:** File → Open → папка проекта → `src/Main.java` → Run.

**Командная строка (Windows):**
```
javac -encoding UTF-8 -d out src/*.java
java -cp "out;lib/postgresql-42.7.10.jar" Main
```
(на Linux/macOS в `-cp` вместо `;` ставится `:`)

## Порядок работы

1. Пункт **2** — ввести имя таблицы (латиница, цифры, `_`). Таблица создаётся, если её нет, и выбирается для работы.
2. Выполнить нужные пункты — результаты сохраняются в таблицу и выводятся в консоль, прочитанные из БД.
3. Последний пункт — выгрузка в `<имя_таблицы>.csv` на Рабочий стол (если его нет — в папку проекта), вывод в консоль и открытие файла в Excel. Файл в UTF-8 с BOM и разделителем `;`, поэтому русский текст в Excel отображается правильно.
